Consider the vector space $\mathbb{R}^3$


Consider the set of vectors  
$$
\{ \mathbf{b}_1=(1,1,1),\mathbf{b}_2=(1,1,-1) \}
$$
which are linear independent!

The set of all vectors
$$
U=\{c_1\mathbf{b}_1+c_2\mathbf{b}_2|c_1,c_2\in \mathbb{R}\}
$$
as we saw $U$ is a subspace. But $U$ is not all vectors in $\mathbb{R}^3$.



The question is can we find vector(s), that we can add to the set of vectors
$$
\{ \mathbf{b}_1, \mathbf{b}_2 \}
$$
such that the extended set is a basis.
